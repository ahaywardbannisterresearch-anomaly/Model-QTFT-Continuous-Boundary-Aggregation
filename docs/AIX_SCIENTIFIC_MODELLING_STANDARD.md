# AIX Scientific Modelling Standard

This repository follows **AIX Scientific Modelling Standard v1.0**.

The authoritative operational copy is maintained in `ahaywardbannisterresearch-anomaly/QTFT-Modelling/docs/AIX_SCIENTIFIC_MODELLING_STANDARD.md`.

## Mandatory notebook sections

1. Purpose and Research Question
2. Hypothesis — Scientific and Plain-English versions
3. Definitions and Guardrails
4. Assumptions
5. Competing Explanations and Controls
6. Methodology — Scientific and Plain-English versions
7. Parameters and Experimental Design
8. Model Implementation
9. Validation and Audit Checks
10. Results — Scientific and Plain-English versions
11. Discussion and Implications — Scientific and Plain-English versions
12. Predictions and Falsification Tests
13. Limitations and Failure Modes
14. Model Assessment
15. Conclusions — Scientific and Plain-English versions
16. Next Tests
17. Revision and Decision Log

New notebooks must be copied from `templates/scientific_model_template.ipynb`, not created blank.

Existing notebooks are retrofitted progressively at their next substantive revision. Historical lineage and negative results must be preserved.
